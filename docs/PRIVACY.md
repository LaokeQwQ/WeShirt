# 数据、隐私与使用说明

[返回首页](../README.md) · [English](PRIVACY.en.md)

## 数据范围

用户住宿楼、任务、通知偏好和协作关系用于对应功能。公开看板、留言与邀请预览使用必要的展示字段，不公开登录凭据或手机号；管理员按权限查看运营所需数据。网站学校 ID 与通道密钥只留在后台，密钥不回显。

公共留言频道与各住宿楼频道都是公开交流区，留言可显示作者住宿楼和身份标签，楼栋频道不等于私密群。**当前占用的洗衣备注、是否使用消毒液及是否已自清洁会公开显示在机器面板。**这些是用户自行填写的记录，勿填写手机号、凭据或其他不希望公开的信息。取衣或清除占用后不再由公开占用接口提供，本人任务历史仍可查看。

巡检数据与上述公开洗衣记录分开：巡检照片和现场备注只对当前有相应楼栋巡检权的志愿管理、总管和管理员开放，撤销权限后不能继续读取。前端会压缩重编码图片，提交前仍应确认照片内容不包含无关人员或个人资料；服务端只校验图片格式及大小，不代替内容检查。巡检记录限 200 条、30 天，过期记录不可读，关联照片在后续读取或提交时按有限批次清理。异常群通知只发送机器和异常提示，不包含巡检照片或备注正文。

CloudBase 仅运行同步触发器；业务数据由 EdgeOne API 使用绑定的持久化 KV 保存。可选 Node 部署使用 `DATA_DIR`，部署方负责访问控制、备份和数据生命周期。

## 遥测

站内遥测接收固定事件、路由类别、楼栋编码和受限数值，按天聚合，最多保留 14 天。它不保存用户 ID、IP、完整 URL 查询参数、消息正文、错误堆栈或访问凭据。基础设施访问日志由部署方另行管理。

错误记录可包含随机事件 ID、状态码和白名单错误类别，用于将页面提示与后台最近错误关联。浏览器运行异常没有 HTTP 响应时状态为 `0`，同一异常对象去重；控制台仅输出这些安全字段，不打印异常正文或堆栈。关闭遥测或启用 Do Not Track 后不上传客户端记录。

遥测尊重浏览器 Do Not Track，用户可在设置中关闭。接口耗时、Web Vitals 和 3D 性能为采样指标，不能据此推算精确活跃人数。

## 用户控制与第三方

通知需要相应通道配置和用户授权，用户可修改个人通知、公告与推送偏好。浏览器权限由系统或浏览器设置管理。AI 为可选能力，用户可关闭或删除记忆；第三方模型处理遵循所选服务自己的数据政策。

用户身份以服务端成员表为准。志愿管理仅获指定楼栋的巡检权；总管和管理员才可治理公开留言，管理员不能升级高权限成员。封停或撤权即时限制已有登录身份。楼群会话 ID 与投递结果由有权管理员管理，不作为公开留言数据返回。

钉钉登录与消息、浏览器推送和设备上游需要对应外部服务。不要把后台凭据、推送私钥或第三方密钥填入浏览器构建变量。

## 使用边界

本项目是独立第三方查询与提醒工具，与设备平台、厂商和学校官方没有隶属关系。只读取设备状态，不启动、锁定或支付机器。登记和排队是协作记录，不能替代实际预约系统或现场确认。

状态受上游和同步周期影响，估计结束时间会明确标识。疑似未取不等于故障，故障与恢复需要复核。全云端托管减少自建服务器维护和单机风险，但平台、网络和上游中断仍可能造成延迟或不可用。

## 公开源码与运行日志

不要提交 `.env`、运行数据、账号池、钉钉凭据、VAPID 私钥、AI 密钥、个人截图和部署缓存。发布前检查文件及历史；已暴露的凭据需要轮换，仅删除文件不能使旧值失效。

同步触发器只返回固定结果分类、状态与事件 ID，失败执行也仅记录这三个字段，不打印 URL 密钥、请求体或响应正文。排查时可分享脱敏的时间、事件 ID、错误类别和状态码。项目及第三方许可说明见仓库许可证与首页致谢。

## 操作记录

业务写操作及后台敏感读取、导出会记录必要的操作者、功能路由模板、目标 ID、状态码、结果与事件 ID，不记录正文、查询参数、密钥、照片或私聊。普通看板轮询不逐条记录，遥测保持匿名聚合。日志每天最多保留500条并按30天有限清理，管理员依查看权限检索，导出也留痕。公开设备看板的个人查看限制不使公开数据变为私有。
