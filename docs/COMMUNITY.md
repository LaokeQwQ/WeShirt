# 频道聊天与部署约定

[English](en/COMMUNITY.md) · [部署](DEPLOYMENT.md) · [机器状态语义](STATE-SEMANTICS.md)

## 频道与身份

| 身份 | 可访问频道 | 频道管理 |
| --- | --- | --- |
| 访客 | 只读公共频道 | 无 |
| 普通登录用户 | 公共频道和当前绑定的本楼频道 | 自己的消息；不能跨楼读写 |
| 宿管志愿者 `volunteer` | 公共频道和本楼频道 | 在获授权的公共/本楼频道发布公告、置顶、设置频道头像及 `@全体` |
| 管理员 `admin` / 总管 `super` | 可跨楼，仍按服务端授予的查看/操作范围校验 | 在获授权频道管理消息；后台权限由角色及授权共同决定 |

打开频道不会修改住宿楼。公共频道仅承载聊天，不关联机器。头像、作者当前住宿楼和身份标记用于辨认消息来源；身份由后端生成，客户端不能自行指定。置顶消息优先显示，公告与频道头像的写入同样验证频道权限。

首次绑定住宿楼不消耗改楼次数，绑定后可自行更改一次；再次更改需联系有权限的管理员。重复保存同一楼不消耗次数。后台停用楼栋会保留原有用户绑定、消息、任务和审计资料，但不再允许该楼的新操作或提醒；重新启用后继续使用原楼标识，不应删除并重建为另一栋楼。

## 聊天与提醒

长按头像可 `@` 对方，长按消息打开回复和举报菜单；加号菜单保留频道成员及有权限用户的 `@全体` 入口。滑动或取消触摸不会触发长按，键盘也可打开菜单。支持图片和短视频。图片压缩后最多 **500 KiB**；视频最多 **4 MiB（4 × 1024 × 1024 字节）**且不超过 **30 秒**，容器为 MP4/MOV、视频编码为 H.264。扩展名、浏览器声明的 MIME 和时长不能替代服务端文件内容校验。频道头像压缩为 256 像素图片，服务端上限为 64 KiB。

举报必须针对有权访问频道内的现存消息。相同用户对同一消息重复提交只生成一条记录，每分钟最多 3 次、每天最多 10 次；后台按消息管理的查看/操作权限和楼栋范围处理。举报保存必要的消息文字快照与原因，附件只保留类型信息；管理员列表不显示举报者身份。消息被删除后，举报证据仍保留。队列最多 500 条，已处理记录保留 90 天，处理操作写入审计。

整点群播报默认每天北京时间 8:00–22:00，分别比较各楼栋机器状态，状态较上次未变时不发送；窗口内失败可有限重试，已成功的楼栋不跟随其他楼重复发送。Markdown 分为空闲、使用中及已确认故障，结束时间缺失时不猜测时长。后台「楼栋通知群」配置整点播报和异常巡检目的群；留空停用本楼通知。旧自定义机器人沿用原桂园洗衣房范围，不发送其他楼栋或未归类机器。未明确归属的临时群不会自动订阅全校播报。

附件按 KV 可接受大小分片，元数据带到期时间。未发送附件保留 30 分钟、已关联附件保留 30 天；同步时通过全局清单有界回收，每次最多清理 20 个过期附件及其元数据、分片和所有者索引，访问已过期附件也会清理。每用户最多 20 个有效附件，达到上限时拒绝新增，不能为腾空间删除仍有效且被消息引用的附件。部署维护者可调整保留策略，不能只隐藏过期元数据而永久保留分片。访问附件仍检查当前用户的频道权限，附件地址不能绕过跨楼限制。

被 `@` 后显示橙色站内提醒，可进入原频道查看并标为已读。已绑定钉钉且启用通知的用户还可收到私信；失败会去重并有限次退避重试。每次发送前再次检查账号、消息、楼栋启用状态和频道权限。此功能不向钉钉群广播，也不做群内 `@`；站内未读提醒与私信送达是两种状态。

## 频道摘要与已读接口

`GET /api/messages/channels` 在每个可访问频道返回 `summary` 和 `unreadCount`。没有消息时 `summary` 为 `null`；否则为 `{ messageId, nick, text, kind, at }`。昵称使用「李**同学」形式，文字摘要最多 80 字，图片和视频仅显示 `[图片]`、`[视频]`。`kind` 为 `text`、`image`、`video` 或 `announcement`。最后一条按消息写入顺序选择，置顶不影响摘要；删除、停用楼栋和当前账号查看范围在服务端过滤。自发消息不增加本人未读，访客未读数为零。

读取目录或 `GET /api/messages?channel=…` 不会标记已读。客户端只在频道处于前台且消息实际显示后调用 `POST /api/messages/read`，正文为 `{ channel, messageIds: [...] }`，每批 1–50 个真实消息 ID。服务端只确认列出的消息，同时标记这些消息对应的 `@` 提醒；未显示的旧消息、随后到达的新消息和其他频道不受影响。响应为 `{ ok: true, channel, unreadCount }`。兼容字段 `throughMessageId` 只确认单条消息，不能与 `messageIds` 同时使用，也不表示清空此前消息。

已读记录按账号使用持久原子存储合并，多个设备的确认不会覆盖彼此。游标不接受客户端时间；消息不存在或已删除返回 404，无当前频道查看权限返回 403，存储暂不可用返回带事件 ID 的 503。禁言与只读成员仍可确认有权查看的消息。客户端应在 404 后刷新消息再确认，不能把目录预取当作阅读。消息、身份和权限仅在单次请求内复用读取结果，不跨请求缓存权限。

## 实时连接

浏览器使用真实 WebSocket 长连接，但中继内部每 **4 秒**读取一次轻量版本号和个人未读数量；这不是数据库变更直接推流。只有版本号或未读数量变化才通知浏览器，消息正文仍经已鉴权 HTTP API 获取。首次连接或重连成功后也补拉数据，避免丢失离线期间的变化。

页面隐藏时关闭连接，恢复可见后重新验证权限、取票并退避重连；连接失败或未启用中继时继续使用 HTTP 刷新。票据在连接后的首帧发送，不放在 URL。后端逐次复核权限并限制短期连接租约，客户端不能通过 WS 发布消息。

中继部署为独立 CloudBase Web 云函数，不替换现有定时同步函数。配置、构建、来源白名单、连接限制和回退步骤见 [WebSocket 中继部署](WEBSOCKET-RELAY.md)。长连接占用云函数执行时间和并发额度，部署者应按实际用量监控；不要宣称此方案无轮询或无成本。
