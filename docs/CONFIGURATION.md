# 配置说明

[返回首页](../README.md) · [English](CONFIGURATION.en.md)

## 必要配置

从 `.env.example` 创建本地 `.env`，或在云平台配置服务端环境变量。启动登录与后台功能前，必须设置独立随机的 `AUTH_SECRET`（至少 16 字符）和 `ADMIN_TOKEN`（至少 8 字符）。缺失时不使用默认口令，相关接口拒绝请求。公开模拟看板可以独立运行。

密钥只存放在服务端；`VITE_*` 会进入浏览器构建，不能用来存储凭据。轮换 `AUTH_SECRET` 会使既有登录、后台票据和派生同步密钥失效。

| 配置 | 用途 |
| --- | --- |
| `AUTH_SECRET` / `ADMIN_TOKEN` | 登录签名与最高管理员入口 |
| `BUILDING_ID` / `BUILDING_NAME` | 看板存储分区及名称，与个人住宿楼偏好分开 |
| `HAIER_MODE` | 默认 `mock`，真实数据使用 `real` |
| `HAIER_URL` / `HAIER_POSITION_ID` | 上游接口与设备点位，按楼层、类别分页 |
| `HAIER_HEADERS` / `HAIER_ACCOUNTS` | 可选服务端请求头或账号池 |
| `HAIER_PAYLOAD` / `HAIER_PAGE_SIZE` | 旧单接口请求体和分页大小，点位模式优先 |
| `HAIER_STATE_MAP` | 状态映射；当前默认 `1` 空闲、`2` 运行、`3` 故障 |
| `HAIER_TIMEOUT_MS` | 上游单次请求超时，默认 8000 毫秒 |
| `SYNC_STALE_MS` / `SYNC_WAIT_MS` | 懒刷新阈值与首次无缓存等待时长 |
| `DINGTALK_APP_KEY` / `DINGTALK_APP_SECRET` | 钉钉内部应用，用于登录和个人消息 |
| `DINGTALK_ROBOT_CODE` / `DINGTALK_AGENT_ID` | 钉钉机器人与应用标识 |
| `DINGTALK_AES_KEY` / `DINGTALK_TOKEN` | 回调解密与验签 |
| `DINGTALK_WEBHOOK` / `DINGTALK_WEBHOOK_SECRET` | 可选群通道与签名密钥 |
| `VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_JWK` / `VAPID_SUBJECT` | 浏览器推送公私钥与联系信息 |
| `ASSISTANT_ENABLED` / `ASSISTANT_ENDPOINT` / `ASSISTANT_MODEL` / `ASSISTANT_API_KEY` | 可选 AI 默认值，可在后台配置 |
| `VITE_API_BASE` | 前端 API 基址，同域生产留空 |
| `PORT` / `DATA_DIR` | 可选 Node 服务端口和持久化目录 |

## 网站与学校

使用部署口令登录 `/#/admin`，在网站管理中设置站名、HTTPS 或站内图标、学校显示名和最多 30 个住宿楼。楼栋代号必须唯一且稳定；更改或删除代号会要求相关用户重新选择。名称可以独立修改。

学校显示名可公开，学校 ID 仅后台可见，并注入旧单接口的 `HAIER_PAYLOAD.schoolId`。推荐多点位流程仍需要单独的 `HAIER_POSITION_ID`，不能把学校 ID 当作点位 ID。

最高管理员可为已完成真实钉钉登录的用户授予以下身份。账号总管与部署口令入口都可管理成员和密钥；管理员只能添加、调整和移除志愿管理，不能修改高权限成员。部署口令入口不可删除，最后一位账号总管不能自行删除或降级。

| 身份 | 权限 |
| --- | --- |
| 总管 `super` | 全部管理功能，包括成员、密钥、AI 配置、内容治理与全楼巡检 |
| 管理员 `admin` | 网站设置、志愿管理授权、内容治理与全楼巡检；不能修改最高配置 |
| 运维 `operator` | 只读后台；不自动获得巡检或内容治理权限 |
| 志愿管理 `volunteer` | 仅巡检获授楼栋；不具备内容治理权限 |
| 普通用户 `user` | 日常看板、任务、预约与交流功能 |

志愿管理必须指定至少一个当前有效楼栋；身份从服务端成员表读取，封停账号不保留管理权，已有登录令牌也随权限变更即时受限。`public` 为公共留言频道保留编码，不能作为楼栋编码。

网站、角色和钉钉覆盖值保存在持久化存储。后台密钥不回显，只显示是否配置；不填写保留，明确清除则停用。初始环境变量仍可用于引导部署。

## 数据与状态

真实模式配置上游接口、点位和必要请求头，先在后台诊断验证。服务端合并同步请求、限制并发；部分楼层或类别抓取失败时保留旧完整快照。人工机位绑定优先决定可信机器类型，不按编号猜测归属。

设备故障需两次不同有效快照、至少间隔 30 秒后确认，恢复同样需两次；未知、过期数据不累计。疑似未取为运行结束至少 5 分钟、原占用任务未确认取走时的派生提示，不等于故障。无上游结束时间时，洗衣按 30 分钟、烘干按 60 分钟估算；真实值出现后优先使用。

## 登记记录

登记洗衣时可选填最多 200 字的备注，并记录是否使用消毒液、是否已自清洁；两项标记默认 `false`。**当前有效占用的备注和这两项记录会在机器公开面板展示**，取衣或清除占用后停止公开，本人任务历史保留登记记录。三项内容均为用户填写，不能证明机器已完成消毒或自清洁，也不会控制机器、投放消毒液或改变洗衣程序。

## 频道与巡检

留言板先展示公共频道、本人住宿楼和其他楼栋频道。它们都是公开交流区，楼栋频道不提供私密群权限；公共频道不关联机器，机器留言与预约放在对应楼栋频道。留言展示作者住宿楼和身份标签。总管、管理员可删除留言、处理禁言，并置顶志愿管理的留言；每频道最多置顶 5 条。

获授权者可在巡检页选择机器，提交正常或异常结果、1–500 字现场备注及照片。服务端按机器真实归属校验楼栋，并在保存前重新核对权限，不接受客户端伪造范围。服务端接受静态 PNG、JPEG、WebP、GIF，最大 500KB、最长边 4096 像素、总像素不超过 400 万；前端压缩重编码，服务端校验文件结构与尺寸，整个请求最大 700KB。记录最多保留 200 条且过期 30 天不可读，淘汰照片分批清理。巡检照片和备注仅对当前获授相应楼栋的志愿管理、总管和管理员开放。

总管、管理员在后台为楼栋配置钉钉群会话 ID，不填写 Webhook 或其他 URL，消息使用已配置的服务端钉钉凭据。仅异常巡检向该楼群提示，同一机器通知尝试间隔至少 10 分钟；通知确认最多等待 12 秒，失败或超时如实记录为未确认送达，超时后通道仍可能实际送达。慢通道不阻塞历史和照片读取，正常巡检不群发。人工异常不会直接把设备改成故障状态，也不会把私有照片或备注正文发到群里。

## 提醒与公告

在钉钉开放平台配置内部应用、登录与机器人回调，使用 HTTPS。后台通知诊断显示实际通道结果。群摘要默认北京时间 8:00–22:00，每整点后 10 分钟内检查，每小时最多成功一次；状态未变或仅倒计时变化时不发。

收藏提醒需要开启个人通知、收藏本楼机器并设置星期时段。成功提醒至少间隔 30 分钟，每次时段最多 3 条，登记后停止当次提醒。预约只提醒同台机器队首，在结束前约 3 分钟与结束阶段分别评估；未知结束时间不能直接判定可用。同步调度过稀可能错过提前提醒窗口。

Markdown 公告支持标题、预览、指定楼栋、生效时间和版本确认；正文经过安全处理。用户可在设置中关闭接收。

生成浏览器推送密钥：

```bash
node tools/gen-vapid.mjs
```

保持 VAPID 密钥稳定，部署后由用户主动授权订阅。Web Push 需要 HTTPS 或 localhost，浏览器支持因平台而异；iOS 通常需通过 Safari 添加到主屏幕。微信、QQ 内置浏览器通常不支持，项目也未实现微信登录或微信消息通道。

## 可选 AI

配置 Responses 兼容服务、模型和服务端密钥后启用。未配置不调用模型，不影响基础功能。调用受频率、每日额度、输出和超时限制，只能通过受限工具读取本人住宿楼数据；不会替用户发送消息或执行代取。

用户可以关闭或删除记忆。Skills 为可查看、确认导入的提示模板，不执行脚本。认证、限流的 `/api/mcp` 仅提供只读机器工具。第三方模型的数据处理以所选服务政策为准。

## 个人功能授权与追踪

总管可在“功能权限与范围”选择任意已存在成员，分别设置各功能能否查看、操作，以及可查看/操作的楼栋；操作范围不能超出查看范围。身份决定能力上限，需要提升功能时先在网站管理授予相应身份。空楼栋范围表示无授权，选择全部表示不限楼栋。网站、系统、模型及全局运营配置只有功能开关，没有按楼范围。总管和部署口令入口保留恢复管理的能力。普通用户不显示后台入口，具备后台查看权的管理员/运维可见。

接口错误显示 HTTP 状态码和事件 ID，可在后台操作日志中搜索该 ID；网络失败的 `client_` ID 仅用于本机定位，状态0表示没有收到服务端响应。日志不保存请求正文、密钥、照片或聊天内容。写请求会去重，失败时先刷新确认结果再重试，避免重复登记或通知。
